## 快速导航

### 日常开发
```
/dev           # 启动开发服务器
/build         # 生产构建
```

### 调试维护
```
/math-debug    # 傅里叶算法调试
/gemini-prompt # Gemini 集成维护
```

### 内容创作
```
/preset math      # 创建数学预设
/preset particle  # 创建粒子预设
/preset scene     # 创建多图层场景
```

### Skill 管理
```
/skill         # 创建新 Skill
/rlaif         # 评估 Skill 质量
```
